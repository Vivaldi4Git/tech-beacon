# 什么是neural-network神经网络？
神经网络是一个大型数学表达式。或者说一个函数。
- input是一个token序列，上一个步骤提到的[02-tokenization](./02-tokenization.md)
- output就是下一个token的概率分布。

例如：
- 输入 "今天天气" → [234, 567, 890] 
- 输出 ["很", "不", "真"]的概率分别是[0.7, 0.2, 0.1]

可以通过这个网址直观的看整个过程👉[Transformer Neural Net 3D visualizer](https://bbycroft.net/llm)
