# ✨ 制作一个光球

本节将介绍如何在 Godot 中制作一个简单且美观的光球效果。

# 🏗️ 节点结构

LightBall (Area2D)
├── CollisionShape2D
├── Sprite2D
└── PointLight2D
  • Area2D：用于检测重叠和触发事件。如果不需要碰撞检测，可以将其替换为 Node2D。
  • CollisionShape2D：用于确定碰撞区域的大小和形状。对于光球，通常选择圆形碰撞体。
  • Sprite2D：用于显示光球的贴图。
  • PointLight2D：用于实现光照效果，控制光的范围和强度。

# 🟡 设置碰撞体

对于光球，建议将 CollisionShape2D 的形状设置为圆形，这样更符合光球的外观和碰撞需求。

# 🎨 设置 Sprite2D

我们可以使用 GradientTexture2D 作为光球的贴图，让光球有柔和的渐变效果。

步骤如下：

  1. 在编辑器中选中 Sprite2D 节点。
  2. 在 Inspector 面板中找到 Texture 属性。
  3. 点击下拉菜单，选择“新建 GradientTexture2D”。

# ✏️ 编辑 GradientTexture2D

设置渐变的颜色和参数，使光球看起来更自然。例如：

  • 渐变起点颜色设置为 #ffe484，让光球呈现柔和的黄色光晕。
  • 渐变终点可以设置为透明，使边缘自然过渡。

# 💡 设置 PointLight2D

PointLight2D 用于在光球周围产生光照效果。它的范围应略大于 Sprite2D，这样光球看起来会发光。

  • 调整 PointLight2D 的范围，使其比 Sprite2D 稍大。
  • 可以适当调整渐变的终点位置，让光照的边缘更柔和，避免光照看起来像被限制在一个方格内。
