# 06-post-training

# supervised fine-tuning（监督微调）

supervised fine-tuning（监督微调）是在 base model（基础模型）预训练完成后，使用人工标注的对话数据集继续训练模型，让模型学会“像助手一样对话”。

# 对话数据的 token 化

打开tiktokenizer (opens new window) ，点击 Add message 按钮：

我们可以看到 IM_START、IM_END 这样的特殊 token。
这些 token 是 GPT-4/ChatGPT 这类模型在对话 token 序列中用来标记“对话轮次”和“角色”的。
通过插入这些标记，结构化的对话就被转换成了一维 token 序列。

# 为什么要这样做？

神经网络只能处理一维 token 序列，并不理解“谁在说话”或“轮次”。
插入这些特殊 token 后，模型就能区分“用户”和“助手”，更好地模拟对话流。

# 消除“魔力感”

我们和 ChatGPT 对话，其实不是在和“神奇的 AI”或影视作品里的 AI 交流。
每次提问，模型其实是在“模拟”如果让这些标注员看到你的问题，他们会怎么写理想的助手回复。
你可以理解为：我们是在和这些被公司雇佣、经过专业训练、拿到详细 labeling instructions（如 helpful, truthful, harmless）的标注员的“统计模拟”对话。
