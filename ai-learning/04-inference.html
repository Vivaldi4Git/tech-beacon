# 04-inference

# intro

上一节讲了什么是neural-network和我们训练他的方式。

训练完成后我们得到的就是一个个大模型 - 本质上可以理解为一个"高级概率机器"。 只不过不过他的样本足够大，所以它可以在一定程度上准确的预测, 然后经过筛选有一定程度上的准确性。

概率预测：

输入："地球是"
可能的预测：
- "一颗行星" (高概率)
- "平的" (极低概率)
- "香蕉" (几乎为零概率)

# 什么是inference 推理

训练完成后，参数就“定型”了，不再变化。 你输入一串 token，模型就用这些参数，经过一系列数学运算（就是神经网络的前向传播），输出下一个 token 的概率分布，然后采样/选择一个 token 作为输出。

# Temperature控制

temperature是控制输出随机性的关键参数：

  • temperature = 0：选择最高概率的token

    例："地球是一颗行星"（选择最安全的答案）

  • temperature = 0.7：平衡随机性和确定性

    例："地球是宇宙中的蓝色珍珠"（有创意但仍合理）

  • temperature = 2.0：大幅增加随机性

    例："地球是一只跳舞的蝴蝶"（非常创意但可能不合逻辑）
