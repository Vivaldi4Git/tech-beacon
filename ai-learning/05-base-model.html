经过前面的过程，我们得到的是一个基础模型（base model），而不是我们日常使用的大模型。

# 什么是基础模型

基础模型本质上是一个互联网文本生成模拟器，它能够生成符合互联网文本统计特征的内容。

# 我们真正需要的

我们实际需要的是一个能够理解并回应我们的智能助手。

# 以GPT-2为例

基础模型通常不会直接发布，因为它还不是一个可用的产品。不过，GPT-2是一个例子：查看讨论 (opens new window)

# 发布基础模型的两个关键要素

  1. 模型架构（model.py）
  2. 模型参数

模型架构相对标准化且数量有限，真正重要的是模型参数。以GPT-2为例，它拥有16亿参数，在1000亿个标记上进行训练。

对比一下模型规模：

  • GPT-2 (2019)：16亿参数，训练数据1000亿标记
  • Llama 3 (2024)：4050亿参数，训练数据15万亿标记
