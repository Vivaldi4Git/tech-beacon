# 什么是 Hallucinations

LLM（大语言模型）在回答问题时，有时会“编造”事实，给出看似合理但实际上错误的信息，这种现象被称为 hallucination（幻觉）。
比如你问“Who is Orson Kovats?”（一个虚构的人名），模型会自信地给出各种答案，但其实这些都是凭空捏造的。

# 幻觉的根源

这种现象的根本原因是：

  • LLM 在训练时，模仿的是数据集里人类标注者的回答风格。
  • 在训练数据中，类似“Who is XXX?”的问题，通常都能查到答案，并且回答都很自信。
  • 所以模型学到的统计规律是：遇到这类问题就要自信地给出答案，而不是说“不知道”。

# 如何解决幻觉

# 自动化检测模型“知道”与“不知道”的边界

Meta 的做法是：

  1. 用 LLM 自动生成关于训练文档的事实性问题，并给出标准答案。
  2. 然后用自家模型（比如 Llama 3）去回答这些问题。
  3. 对比模型的回答和标准答案，如果模型答对了，说明它“知道”；如果答错或答不出来，说明它“不知道”。

对于模型“不知道”的问题，在训练数据中加入“I'm sorry, I don't know”或类似的拒答，作为正确答案。
这样模型在后续训练中就能学会：遇到自己不确定/不知道的问题时，应该拒绝回答，而不是胡编乱造。

# Web Search：让模型学会查资料

人类遇到不知道的问题会去查资料，当模型遇到不知道的问题时也可以上网查阅。

  • 引入特殊 token：比如 search_start 和 search_end，模型可以在生成时输出这些 token，表示要进行搜索。
  • 当检测到 search_end，外部程序暂停模型生成，将 start 和 end 之间的内容 paste 到搜索引擎上进行搜索，自动把搜索到的内容（如 Bing、Google 的结果）插入到上下文窗口（模型每次生成答案时，能“看到”的就是你输入的内容和它自己生成的内容）。
  • 搜索结果作为新输入，模型继续生成答案，此时能直接引用最新查到的信息。

举例：
假设你问模型“某本书第一章讲了什么？”
如果你直接问，模型只能靠参数里的“模糊记忆”来回答，可能会幻觉。
如果你把第一章的原文贴到 prompt 里（上下文窗口），模型就能“直接看到”，总结得更准。

# Knowledge to Self：让模型正确“自我介绍”

很多人会通过问模型 “What model are you?” “Who built you?”
如果模型回答：

I was built by OpenAI, based on the GPT-3 model.

人们就会倾向于认为这是一个基于 OpenAI 做的模型。
其实这完全是胡编乱造（nonsense），本质上是模型在模仿训练数据中最常见的答案。

如何让模型正确地“自我介绍”？

  • 在训练数据中硬编码：比如在 SFT（监督微调）数据集中，专门加入“你是谁”“你叫什么名字”等问题和标准答案。这样模型就会学会在遇到这些问题时给出指定的回答。
  • 用 system message（系统消息）：在对话开始时，给模型一个隐藏的系统提示，比如“你是由 OpenAI 开发的 AI 助手，名字叫 ChatGPT，知识截止到 2024 年底”等。这样模型在生成回答时会参考这些信息。

所以，解决幻觉问题，本质上就是通过补全训练数据，让模型学会在不确定时“拒绝回答”，而不是胡编乱造。这和我们写代码时加异常处理、边界判断的思路非常类似。
