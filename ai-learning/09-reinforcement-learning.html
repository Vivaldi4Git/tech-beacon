# 09-reinforcement-learning

训练 AI 其实很像我们自己的学习过程。我们上学时，先看教科书，了解背景知识，这就像模型的 pre-training（预训练）。
介绍完一段知识后，通常会有一两个例题和答案，这对应 post training 阶段，由专家（human labeler）写出问题和标准答案。
预训练像看教科书，SFT（监督微调）像看专家解题。

但到这一步，我们还是不会做教科书之外的题目。于是就有了“作业”——
Reinforcement learning（强化学习）就像自己做题、自己练习，然后对照答案，知道哪里做对了、哪里做错了。当然，这里的“自己”指的是大模型。

# the difference vs human labeler

LLM 处理的是一维的 token 序列，而我们人类用的是自然语言。
可以把这理解为我们和模型像是说不同的语言，这也导致了思考方式的不同。

所以当 human labeler 训练 AI 时，会有一个问题：

human labeler 并不知道什么样的 token 序列对 LLM 更友好，可能写出让 LLM 很难完成计算的答案。
比如我们看到先给出答案再给出过程没问题，但对 LLM 来说，可能很难在一个 token 内完成所有推理。

所以 LLM 的练习过程要让它自己去探索最合适的解题路径（一维 token 序列），并在此基础上训练。就像我们做对了一道题，后面也会用类似的方法去解题。

# AlphaGo

只靠模仿人类专家（监督学习），模型永远达不到人类顶级水平，因为那只是模仿。
但通过 RL（强化学习），模型可以超越人类。
