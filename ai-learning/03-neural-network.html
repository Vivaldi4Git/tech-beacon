# 什么是neural-network神经网络？

神经网络是一个大型数学表达式，或者说一个函数。让我们从基本组成部分来理解它：

# 1. 输入输出

  • input是一个token序列，我们会从收集到的token中pick up 一个window[token1, token2, token3]
  • output就是下一个token的概率分布

例如：

  • 输入 "今天天气" → [234, 567, 890]
  • 输出 ["很", "不", "真"]的概率分别是[0.7, 0.2, 0.1]

# 2. 网络参数(Parameters)

神经网络的"大脑"由大量参数(weights)构成：

  • 包含数十亿个可调节的数值参数
  • 这些参数初始时是随机设置的
  • 通过训练过程不断优化调整
  • 训练完成后的参数存储了网络学到的所有"知识"

# 3. 训练阶段

训练的目标是让模型学会“给定一串 token，预测下一个 token 的概率分布”。 训练时会不断地用真实的下一个 token 来“纠正”模型的输出，让它越来越接近真实分布。
